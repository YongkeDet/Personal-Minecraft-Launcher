# Personal MC Launcher

A personal Minecraft Java Edition launcher project intended for a single user: its developer.

## Purpose

The goal is to manage my own Minecraft installations and mods through a personal desktop launcher. The launcher is intended for my use only. There are no plans to release the application publicly, provide a service to other users, or monetize it.

## Planned CurseForge API use

Subject to API access approval and the applicable terms, the planned integration will:

- Search for mods and view project information.
- Retrieve file information relevant to the selected Minecraft version and mod loader.
- Download mod files for my own installations only where CurseForge and the authors permit third-party distribution.

Requests will be made on demand for one user's activity. The project is not intended for bulk collection, automated mirroring, or a public API proxy.

## Respect for mod authors

- Show author attribution and links to the original CurseForge project pages.
- Respect authors' third-party distribution settings and applicable licenses.
- Do not bypass disabled downloads or access restrictions.
- Do not rehost or bundle mod files for other users.

This project has no revenue. It has no advertising, subscriptions, paid features, donation collection, or other monetization plans.

## Repository scope

This repository contains project documentation only. It does not contain launcher source code, executable releases, mod files, or API credentials. The launcher itself is not publicly available through this repository.

## Status

CurseForge API integration is planned and subject to approval. This document does not claim that API access has already been granted.
